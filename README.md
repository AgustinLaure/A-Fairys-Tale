Keybinds:

A - D : Side movement
Space : Jump
E : Pickup item
M1 : Use held item
Tab : Toggle crafting mode
Up arrow - Down arrow - Left arrow - Right arrow : Crafting input
Escape : Pause

Cheats:

On folding level:
1 (numpad): toggle Snap Points
2 (numpad): toggle Drag Markers
3 (numpad): toggle Target Limits
